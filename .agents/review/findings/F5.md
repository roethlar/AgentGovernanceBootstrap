# F5: explicit Git re-includes were treated as ignores

Status: Complete in development source; [integration/deletion verified](../2026-11-17-completion.md). Public release pending.
Source: [Bixi #5](https://github.com/roethlar/Bixi/issues/5).

`check_committability` now uses Git's quiet yes/no result and requests
NUL-delimited provenance only for an effective ignore. Fatal probe errors
refuse before writes; existing destination safety checks run first.

Scope: `tools/refresh.py`, `tests/test_refresh.py`, and approval/progress records.
Cases cover whitelist re-includes, a still-excluded parent, a literal
escaped exclamation, and a fatal ignore probe. Existing adapter-ignore and
symlink guards remain active.

Bite proof: replacing only the runtime source with `a199383` made the
re-include and fatal-probe tests both fail for their expected assertions;
the fixed source was restored and both pass. Full suite: 229 tests passed
with one filesystem-specific skip. No product release or self-refresh.
